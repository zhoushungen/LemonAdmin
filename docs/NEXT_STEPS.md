# 后续扩展

后续业务开发必须基于 `docs/DEVELOPMENT.md`：

1. 完善密码修改、重置密码、登录日志和管理员批量导入事务接口。
2. 增加字典管理、任务管理和文件管理页面。
3. 按 `IObjectStorage` 实现腾讯云 COS 与阿里云 OSS 适配器。
4. 接入“不爱收纳”的房间、收纳位、分区、物品、标签、预警、会员和支付模块。
5. 新业务表统一考虑 `department_id`、`created_by`，并在列表、详情、修改、删除、导入、导出中应用 `IDataScopeService`。
6. 增加数据权限单元测试、MySQL 集成测试与 CI。
7. 确有兼职归属需求时再评审管理员附属部门；附属部门默认不扩大数据权限。
