# 变更日志

## v1.4.0

- 后端由五项目精简为四项目，移除 `Lemon.Shared`。
- 移除 Mapster，改为显式 DTO 映射。
- 移除 JWT 中重复权限 Claims 和无调用方法。
- 修复异常角色可能兜底为全部数据的高风险问题。
- 普通管理员的角色、主部门在登录、刷新、数据范围和账号切换时统一 fail-closed。
- 未知对象存储 Provider 改为启动失败，不再静默回退本地。
- 加固菜单父子关系、Correlation ID、密码 Hash 解析、Refresh Token 并发轮换和前端 localStorage。
- 整理依赖所属项目、授权注册和压缩成单行的 Controller。
- v1.4 无数据库结构变更。

## v1.3.0

- 角色新增五档数据范围：全部、主部门及下级、仅主部门、主管部门及下级、仅本人。
- 管理员继续保持一个主部门和一个角色，不增加多部门关系表。
- 部门新增主管管理员，一个管理员可以主管多个部门。
- 新增 `IDataScopeService`，按请求统一计算当前数据范围。
- 管理员列表、详情、部门列表与写操作、审计日志接入数据权限。
- 审计日志增加部门快照，账号切换后按目标账号的数据范围执行。
- 前端角色页增加数据范围配置，部门页增加部门主管选择。
- 增加部门父子循环校验、普通管理员主部门数据库约束和 v1.3 迁移文档。
- 修复“仅本人”范围可能看到同部门其他管理员的问题。
- 修复历史已删除普通账号缺少部门时可能导致迁移失败的问题。

## v1.2.0

- 管理员与角色调整为一对一，`role_id=NULL` 表示唯一超级管理员。
- 普通管理员必须绑定一个角色，角色名称保持自由。
- 管理员新增、编辑、启停和系统设置修改改为超级管理员专属。
- 新增可配置账号切换，支持安全切回和 Redis 会话失效。
- 审计日志区分真实操作者和当前生效身份。
- 新增账号切换、配色方案、整体字号三个系统开关。
- 前端加入账号切换入口、状态提示条和开关控制。
- 加固生产环境默认配置和数据库迁移安全。
- 新增代码审查与 v1.2 迁移说明。
- 修复导入管理员默认密码、失败操作漏审计、异常身份退出和前端操作按钮未按权限隐藏问题。
- 关闭账号切换开关后，现有模拟 Token 立即失效。
- 收紧文件上传白名单和本地存储路径边界，并修复 CSV 公式注入风险。
- 修复 401 后前端残留旧登录状态导致的重定向循环。
- 将 API 全局共享限流调整为按客户端 IP 独立限流。

## v1.1.0

- 框架命名为 Lemon，后端项目统一 `Lemon.*`。
- 新增 `lemon-ui`、部门管理、菜单管理、七牛云 Kodo 和通用列表能力。
